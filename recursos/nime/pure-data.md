# Pure Data (Pd)

- **Categoria:** NIME / Programação Visual
- **Licença:** BSD (open source)
- **Site oficial:** [puredata.info](https://puredata.info)

---

## Descrição

Pure Data (Pd) é uma linguagem de programação visual para criação sonora e multimídia. Permite construir sintetizadores, sequenciadores e interfaces interativas a partir de objetos gráficos conectados por cabos virtuais.

## Sugestões pedagógicas

1. **Introdução:** Criar um oscilador simples e explorar frequência e amplitude.
2. **Intermediário:** Construir um sequenciador de ritmos.
3. **Avançado:** Integrar sensores (Arduino) para controlar parâmetros em tempo real.
