# Registrar uma pista

## O que está acontecendo agora?

Escolha o registro que cabe neste momento:

- **Escutamos** — um som, ritmo, ruído ou mudança;
- **Tentamos** — algo novo, uma alteração ou uma hipótese;
- **Descobrimos** — algo que não sabíamos antes.

### Registro rápido

**Tipo:** _escutamos / tentamos / descobrimos_

**Nota curta:**

> [campo de texto ou áudio]

**Tags opcionais:** `erro` · `hipótese` · `som` · `gesto` · `código` · `sensor`

**Anexo opcional:** foto · áudio · código · captura de tela

[Guardar pista]

> Não é preciso escrever bonito. Uma palavra, uma foto ou um áudio já deixa uma pista para o Diário.
